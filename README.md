# 林间小屋 · The Cabin in the Woods

黄昏森林里的一座小木屋，纯前端实时 3D 场景（Three.js，无构建步骤）。

- 程序化生成：木纹/石基/瓦片/落叶/窗光纹理全部由 Canvas 绘制
- 森林：松树 + 阔叶树（实例化）、地被、蕨草、石头、倒木
- 小屋：木板墙、石基、双坡屋顶、山墙、老虎窗、烟囱炊烟、门廊、灯笼、柴堆、晾衣绳、花盆
- 电影感：低角度逆光、体积雾、暖窗光 + 冷天光、Bloom、暗角、胶片颗粒、轻微色差、2.35:1 黑边
- 交互：自动运镜 / 拖动环视 / 双指缩放 / 画质切换

打开方式：直接访问 Pages 地址即可，无需安装。
